# Le Silence des Cloches

Une nouvelle aventure (histoire, cartes, combats) jouable dans le navigateur :
**https://vflam.github.io/silence-des-cloches/**

Le jeu utilise les graphismes et les sons de **votre propre cartouche** : la page demande la ROM
(copie de votre cartouche), l'analyse et en extrait les graphismes et les sons **dans votre
navigateur**. Rien n'est envoyé sur Internet ; le résultat est gardé dans le navigateur pour
les visites suivantes.

Versions acceptées : Zelda no Densetsu: Kamigami no Triforce (Japon v1.0 et v1.2),
The Legend of Zelda: A Link to the Past (États-Unis), La Légende de Zelda: A Link to the Past
(France).

Ce dépôt ne contient que le site compilé (moteur Godot, page, outils d'extraction). Il ne
contient **aucun graphisme, son ni donnée du jeu d'origine**.

Projet de fan non officiel et gratuit, sans lien avec Nintendo. *The Legend of Zelda* et
*A Link to the Past* sont des marques de Nintendo.
